# homebrew-tap

Homebrew formulae for my tools.

```
brew install tjwaterman99/tap/weir
```

| Formula | What it is |
|---|---|
| `weir` | Keeps local, read-only mirrors of your repositories up to date. [tjwaterman99/weir](https://github.com/tjwaterman99/weir) |

The formulae in `Formula/` are written by each project's release workflow. Do not edit them by hand.
